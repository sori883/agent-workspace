# 最後に確認する6観点

想定読者と用途を一文で確認してから、完成稿を初見のつもりで読む。lintの指摘がないことと、文章の目的を果たすことは別に確認する。

| 観点 | 問い |
| --- | --- |
| 自然な文体 | 定型句、無理な共感、同じ語尾や構文が内容より目立っていないか |
| 情報密度 | 前置き、同じ説明の言い換え、不要な補足を取り除けるか |
| 探しやすさ | 結論、手順、必要な条件を迷わず見つけられるか |
| 論理と根拠 | 主張と理由がつながり、具体例・数値・出典で確かめられるか |
| 誠実さと著者の声 | 確信度、動機、引用の意味を保持しているか。実体験を作っていないか |
| 文書自身の説得力 | 文書が掲げる方針を本文でも実行しているか |

fullでは各観点の問題箇所と改善理由を示し、影響が大きいものを直す。quickでは通読で確認する。主観的な点数の達成を終了条件にせず、具体的な問題が解消されたか、残す理由があるかで判断する。
