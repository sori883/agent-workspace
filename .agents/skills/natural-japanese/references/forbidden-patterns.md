# 定型句を文脈で判断する

ここにある語句は一律の禁止語ではない。内容を運ばず、同じ型を反復している箇所を探す材料にする。必要な留保、引用、正式な用語は保持する。

| 表現の型 | 例 | 確認すること |
| --- | --- | --- |
| 結論・まとめ口調 | と言えるでしょう、いかがでしょうか、総じて | 結論そのものを直接書けるか。問いに実際の役割があるか |
| 過剰な強調 | 非常に重要、極めて重要、ポイントは | 何がどう重要かを具体的に書けるか |
| 空疎な導入 | 見ていきましょう、紹介していきます | 予告なしで本題に入れるか |
| 曖昧な留保 | 一概には言えません、個人差がありますが | 必要な条件や限界を具体化できるか。留保そのものは消さない |
| 姿勢の宣言 | 正面から扱う、深掘りする、言語化する | 実際に行う説明や分析を示せるか |
| 空虚な形容 | 多角的、包括的、核心的、鍵となる | 視点、対象、根拠が本文にあるか |
| 否定から肯定への対比 | 〜ではなく、〜だけでなく | 比較対象や訂正する誤解が実在するか |

「重要なのは」「このように」「不可欠」「ポイントは」「さて、」は参考情報として扱う。通常の語や引用に反応しただけなら、理由を付けて残す。

文末や語彙の統計も同じように使う。`nominal_ending`は長い本文に体言止めがない場合の参考指摘であり、体言止めを増やす指示ではない。語彙多様性が低くても、同じ製品名や専門用語を使い続けることは自然である。

具体性の不足は[推敲手順](revision-guide.md)、直訳調は[翻訳調の資料](translationese.md)を参照する。
