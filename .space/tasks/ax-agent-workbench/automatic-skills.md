# 標準エージェントとスキルの自動利用

## 依頼と終了条件

2026-10-08の利用者の依頼。依頼内容に応じてスキルを自動で見つけ、必要な本文を読み込む。`/`から明示的にも指定できる。通常画面は標準エージェントに統一し、エージェントを選択・登録・編集する負担をなくす。スキルへの従い方に関するモデル性能の調査は今回は追加しない。

- ワークスペース内で本人が利用できる公開版だけを候補とし、私有データと権限を保つ。
- 自動利用では概要と本文を分け、モデルが必要なスキルを選んで読む。全文の一括注入や文字列ルールだけによる選択では代替しない。
- `/`の候補から公開版を指定でき、重複名・キーボード・日本語入力・版の固定・送信の再確認を扱う。
- 標準エージェントで相談・既存の隔離Python作業を継続できる。旧エージェント定義と履歴は破壊しない。
- 適切な自動テスト・画面操作・実行経路の確認と独立レビューを行い、意味のある変更一式としてPRを納品する。
- ローカルへ反映し、通常利用のAI接続は有効のまま維持する。既存の料金・呼出数の上限は変更しない。
